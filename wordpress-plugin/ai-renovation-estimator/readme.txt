An interactive 6-step AI renovation estimator that captures leads and provides provisional cost estimates.

== Description ==

Interactive renovation cost estimator for interior designers and renovation contractors in Singapore.

Features:
* 6-step wizard: Property type > Scope of works > Design styles > Floor plan > Contact > Estimate
* Property types: BTO/SBF, Resale HDB, Condo, Landed, Commercial
* Categorised scope of works (hacking, carpentry, electrical, plumbing, etc.)
* 9 design style options - pick up to 3
* Optional floor plan upload
* Lead capture with name, email and WhatsApp
* Cost breakdown with property-type multipliers
* Free gift CTA with appointment booking
* Leads saved to WordPress admin + email notification

== Installation ==

1. Upload the `ai-renovation-estimator` folder to `/wp-content/plugins/`
   OR go to Plugins > Add New > Upload Plugin and select the zip file
2. Activate the plugin in the WordPress 'Plugins' menu
3. Add the shortcode `[renovation_estimator]` to any page or post
4. Leads will appear under 'Reno Leads' in your WP admin menu
